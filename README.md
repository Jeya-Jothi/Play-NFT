# Play NFT

Play NFT is a modern and responsive web application for exploring digital artworks and NFT collections.  
It focuses on clean UI, smooth interactions, and an engaging browsing experience.

## Live Demo

https://play-nft-e07i.onrender.com

## Features

- Responsive design for mobile, tablet, and desktop
- Smooth animations and transitions
- Artwork preview grid
- Clean and modern UI
- Optimized asset loading

## Tech Stack

- React
- Tailwind CSS
- Framer Motion

## Getting Started

### Installation

```bash
npm install
npm run dev
```
